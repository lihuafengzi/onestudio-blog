你好，欢迎来到 **OneStudio｜一人造物**。

这里会记录我作为独立开发者做产品的过程：从一个模糊的念头，到它慢慢变成可以使用的东西。也会写下踩过的坑、学到的经验，以及那些还没来得及整理的小想法。

我相信，独立创作不必一开始就声势浩大。先做一个小东西，让它真实地存在，然后继续往前。

```js
const today = new Date();
const nextStep = "keep making";

console.log(`${today.toDateString()}: ${nextStep}`);
```

如果你也在做有趣的事情，欢迎通过页脚的联系方式来聊聊。
